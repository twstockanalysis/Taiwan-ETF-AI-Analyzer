# GoodCat character assets

These five original gray-and-white GoodCat illustrations were generated for
this repository with OpenAI's built-in image generation on 2026-08-26. The
approved idle illustration is the identity anchor: low sleepy eyelids express
the cat's usual lazy mood. Active states use restrained, natural feline body
language instead of human-like gestures. No third-party character artwork is
included in these files.

Use of the generated assets remains subject to the applicable OpenAI service
terms and this repository's license. Keep this provenance note with the files.

| File | State | Intended use |
| --- | --- | --- |
| `goodcat-idle.png` | `IDLE` | Home, empty or waiting state |
| `goodcat-attentive.png` | `ATTENTIVE` | Raised head and forward ears during input |
| `goodcat-working.png` | `WORKING` | Natural crouch while calculation runs |
| `goodcat-ready.png` | `READY` | Alert stance and raised tail for completion |
| `goodcat-caution.png` | `CAUTION` | Sideways ears for missing data, risk or shortfall |

All production files are PNG images with real alpha transparency. Character
images supplement visible Traditional Chinese state text; they never replace
labels, result status, risks or warnings.
