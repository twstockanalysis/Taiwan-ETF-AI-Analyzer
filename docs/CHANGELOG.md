# Changelog

All notable changes to the TW ETF AI Analyzer project are
documented in this file.

## 2026-07-28

### Added

- Web-oriented backend and frontend project structure
- SQLite connection module
- SQLite initialization module
- ETF master database table
- Database schema verification tool
- Automated database tests
- Initial system architecture documentation
- Project roadmap

### Changed

- Project direction changed from Excel-first to website-first
- ETF database reduced to decision-relevant fields
- Database connection now supports custom test databases

### Fixed

- ETF code is explicitly defined as NOT NULL
- SQLite foreign key enforcement is enabled for every connection
